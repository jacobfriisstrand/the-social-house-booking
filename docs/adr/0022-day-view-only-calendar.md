# Day view only in v1.0

The calendar is a single day grid: 30-minute rows from 09:00 to 22:00, one column per room, for admins and members alike. The spec (Bilag 1, "Calendar and notice board") lists day, week and month views; week and month are deferred to a later version because the day grid already answers "is a room free now", the notice board and invoicing table cover the rest of the spec's calendar needs, and a week grid across six rooms is unreadable. Design rules for the grid are in `docs/design/DESIGN.md`.
