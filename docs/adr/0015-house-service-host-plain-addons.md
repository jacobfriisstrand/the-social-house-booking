# House Service and House Host are plain add-ons

House Service and House Host are ordinary add-ons with the same shape as every other in the catalogue: name, description, price, and pricing model — and no recommendation or automatic pre-selection in v1.0. Guidance about when House Host fits (or when the small-meeting limits on House Service apply) lives in the description, which the booking flow already shows under the checkbox; there is no separate guidance text and no "house service"/"house host" flag on the add-ons table. The two are seeded into every environment (local `seed.sql` and a DML migration for cloud databases) so the catalogue is identical everywhere; the House Host base price in the catalogue is never edited per booking — a per-booking adjustment lives on the booking's add-on line only. The admin can still edit name, price, model, and description like any other add-on.
